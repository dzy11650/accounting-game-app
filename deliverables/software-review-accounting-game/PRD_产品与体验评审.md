## 一、产品定位与定位合理性

### 1.1 定位清晰度评估

**结论：定位清晰，与目标用户高度匹配，具备良好产品定位。**

- **核心定位**：「零基础会计入门教学 App」，通过情景化关卡（记账、凭证、报表、成本、税务筹划、持续经营）将枯燥会计知识转化为可互动的小游戏，定位精准，未与同质化产品产生冲突。
- **目标用户匹配**：面向零基础会计初学者，从最基础的「实收资本 / 应付职工薪酬 / 应交税费」等概念讲起，配套 NPC 对话与知识点讲解（story.js 中每个步骤均带 `teach` 知识点），零会计背景用户可自然上手。
- **平台定位一致性**：Web、Electron 桌面版、Tauri 桌面版、Capacitor 安卓原生 App 四端均封装竖屏（420×780 或移动端安全区），定位一致，不存在体验割裂的核心风险。

### 1.2 多平台一致性风险提示

| 风险点 | 评估 | 说明 |

## 三、用户流程与体验逻辑

### 3.1 核心经营流程顺畅度

**结论：核心流程（选公司→选经营项目/难度→开局经营→月度结账→结算）顺畅，无明显断点或逻辑卡死。**

核心流程各环节实现逻辑如下（依据 Game.jsx）：

| 流程环节 | 实现逻辑 | 体验评价 |
| --- | --- | --- |
| 选公司 | 首页展示 5 种公司类型 → 点击进入 Game.jsx 选公司（`chooseCompany`） | ✅ 顺畅，动态展示公司信息与经营项目 |
| 选经营项目/难度 | 选公司后展示该公司的经营项目与三档难度（`pendingCompany` 暂存） | ✅ 顺畅，按公司类型动态呈现，贴合企业实际 |
| 开局经营 | `createCompany` 生成空壳公司 → 第一章出资/纳税人决策注入资金 → 进入经营步骤 | ✅ 顺畅，资金由决策注入，规模联动后续经营 |
| 月度结账 | 每月执行月末结账（折旧+计息+房租摊销）→ 缴税 → 结转本年利润 | ✅ 顺畅，权责发生制体现完整，无需手动逐步操作 |
| 结算 | 出三张报表 → 四维评分（雷达图+星级）→ 决策后果回放 → 里程碑成就 → 本地排行榜 | ✅ 顺畅，游戏化玩法闭环完整 |

**潜在体验风险（P1）：**
- 硬核模式（`hardcore`，容错 0 次）错一次即失败，容错提示与后续反馈机制依赖错误边界（`ErrorBoundary`）兜底，若渲染期异常可能导致失败展示异常，需 QA 重点验证。

### 3.2 营销/税务筹划/邪道玩法边界设计

**结论：边界设计合理，合规提示清晰，邪道玩法风险可感知。**

| 设计维度 | 实现情况 | 说明 |
| --- | --- | --- |
| **正道 vs 邪道边界** | ✅ 清晰 | 合理避税（`smallBenefit`/`rndDeduction`/`vatSmall`）为正道，邪道（拖欠工资/调账/拖欠税款/虚开发票）明确标注「邪道」并提示刑事红线（`evilFakeInvoice`、`evilTaxAdjust`、`evilTaxOwe`）。 |
| **研发加计扣除合规限制** | ✅ 合规 | v2.0.4 新增：研发加计扣除仅限科技类企业，非科技类自动剔除不适用项并提示，避免设定脱戏（README 与代码双重防护）。 |
| **合规提示清晰度** | ✅ 清晰 | 邪道操作均有 Toast 提示（如「虚开发票是刑事红线，随时可能爆雷」）、决策诊断卡片（`analyzeDecision`）合规度评估、月度体检合规提示，合规风险可被玩家感知。 |
| **邪道后果可量化** | ✅ 量化 | 邪道操作累积违规次数、稽查概率、滞纳金、罢工风险等，年终爆雷（`maybeEvilBlowup`）机制让邪道代价具象化，合规价值体现明确。 |

### 3.3 报表生成与游戏化玩法合理性

**结论：报表生成逻辑严谨，游戏化玩法（评分/回放/排行）合理有效。**

| 玩法 | 实现情况 | 评价 |
| --- | --- | --- |
| **报表生成** | 三张表（资产负债表/利润表/现金流量表），报表视图自动校验平衡（资产=负债+权益、收入-费用=利润、现金流合计=净增加），`ReportView.jsx` 实现校验逻辑 | ✅ 严谨，平衡校验防止数据错误，教学价值高 |
| **结算评分** | 四维雷达图（盈利/现金流/低风险/合规度），综合星级（3 星/2 星/1 星/0 星），动态展示 | ✅ 合理，雷达图直观呈现经营能力，星级引导学习目标 |
| **决策后果回放** | `trackChoice` 记录关键决策快照，`decisionInsights` 量化对比（如小规模 vs 一般纳税人少缴增值税金额、借款利息影响），结算页展示 | ✅ 合理，帮助玩家复盘决策得失，优化策略 |
| **排行榜** | 本地排行榜（按综合分排序，含模范 NPC 参照线）、多公司对比（各类公司最佳成绩横向对比） | ✅ 合理，鼓励玩家多维度对比，提升学习深度 |
| **决策后果回放边界** | 决策回放基于玩家已选决策，不虚构反事实路径，仅展示差异，不诱导投机，符合教学定位 | ✅ 合理，风险可控，符合游戏化教学伦理 |

基于上述评审发现，按 **P0 高优 / P1 中优 / P2 低优** 分级，给出可落地、优先级分明的完善建议：

### P0 高优建议

| 优先级 | 建议内容 | 依据 | 影响 |
| --- | --- | --- | --- |
| **P0** | **补齐 Capacitor 原生插件配置，明确跨端原生能力边界** | `capacitor.config.ts` 中 `plugins: {}` 为空，未声明原生插件；若后续需要本地存储扩展、推送等原生能力，安卓端需额外补齐插件配置，存在跨端能力不一致风险。 | 影响多平台扩展能力一致性，避免后续跨端功能缺失或体验差异。 |
| **P0** | **优化硬核模式失败兜底，强化失败场景的提示与重开引导** | 硬核模式（容错 0 次）错一次即失败，依赖 `ErrorBoundary` 兜底；若渲染期异常可能导致失败展示异常，且失败后重开引导需明确。 | 提升硬核模式体验稳定性，降低用户操作挫败感，确保失败后能顺畅重开。 |

| 优先级 | 建议内容 | 依据 | 影响 |
| --- | --- | --- | --- |
| **P1** | **统一桌面端（Electron/Tauri）与移动端的底部导航与安全区交互** | 桌面端固定 420×780 竖屏，移动端适配安全区，虽已做基础适配，但底部导航在桌面端的点击反馈、安全区适配需进一步统一，避免跨端交互差异。 | 提升多平台交互一致性，避免用户在不同平台体验不一致。 |
| **P1** | **完善邪道玩法「爆雷」的预警机制，降低玩家冒险风险感知** | 邪道爆雷仅在每年 12 月概率触发，预警较晚；建议在中长期累积违规痕迹时（如累计违规次数 ≥ 3 次）即弹出风险预警提示，强化合规价值引导。 | 提升邪道玩法风险感知，引导玩家在合规与收益间平衡，符合教学定位。 |

| 优先级 | 建议内容 | 依据 | 影响 |

主要亮点：
1. 核心经营流程（选公司→经营→结账→结算）闭环完整，权责发生制、会计恒等式校验逻辑严谨，教学价值高。
