# 软著 + 个体户 + 上架国内商店 — 完整时间线 Checklist

> 目标：把"会计小当家教学软件"从个人项目推进到国内主流安卓商店可下载
> 总周期估算：软著下证 1.5–2 个月（并行做分发，不影响当前使用）

---

## 阶段 0：立即做（第 1 周，零成本）

- [ ] **提交软著申请**（免费，中国版权保护中心）
  - [ ] 注册账号 + 实名认证（刷脸/银行卡）
  - [ ] 在线填表（参考《软著申请表填写模板.md》）
  - [ ] 运行 `gen_source.mjs` 生成源代码材料
  - [ ] 整理《用户手册》PDF（参考本包内手册草稿）
  - [ ] 提交 + 邮寄/现场交材料
  - [ ] 记录"受理通知书"编号，设为待办跟踪
- [ ] **并行启动无资质分发**（不需要软著）
  - [ ] 注册酷安开发者账号，发布"会计小当家"
  - [ ] 注册蒲公英，上传 app-release.apk 生成内测二维码
  - [ ] 在 README 的下载章节补充酷安/蒲公英入口

## 阶段 1：主体准备（第 1–3 周）

- [ ] 决定申请主体：**个人** or **个体工商户**
  - 个人：软著归个人，但上国内商店几乎都要企业/个体户资质
  - **个体工商户（推荐）**：成本最低的企业形态，可办营业执照，用于商店上架
- [ ] 办理个体工商户营业执照
  - [ ] 当地政务服务网 / 市场监管局窗口
  - [ ] 经营范围含"软件开发"/"信息技术服务"
  - [ ] 成本：基本免费（部分地区刻章工本费）
  - [ ] 周期：3–7 个工作日
- [ ] 用个体户资质**重新申请软著**（若阶段0用了个人，可补变更或重新申请；建议阶段0直接用个体户）

## 阶段 2：软著审查期（第 2–8 周）

- [ ] 每周查一次审查状态
- [ ] 收到"补正通知书"后 **30 日内**补回材料
- [ ] 下证后下载电子证书，打印存档
- [ ] 软著登记号格式：`2026SRxxxxxx`

## 阶段 3：签名证书（与软著并行，第 3–4 周）

> ⚠️ 当前 APK 是自签名（debug keystore），进正规商店**必须**换成正式发布证书

- [ ] 生成正式发布密钥库（release keystore）
  ```
  keytool -genkey -v -keystore kjxdj-release.keystore \
    -alias kjxdj -keyalg RSA -keysize 2048 -validity 10000
  ```
- [ ] **安全备份** keystore + 密码（丢失=永久无法更新 App）
- [ ] 配置 `android/app/build.gradle` 用 release keystore 签名
- [ ] 重新打包 `app-release.apk`
- [ ] 在 Gitee Release 更新为正式签名包

## 阶段 4：上架国内商店（软著到手后，第 9–12 周）

按优先级顺序上架（每家独立审核，材料可复用）：

- [ ] **华为应用市场**
  - [ ] 注册华为开发者联盟（企业/个体户资质）
  - [ ] 软著证书 + 营业执照 + 隐私政策
  - [ ] 提交 APK + 截图 + 应用介绍
  - [ ] 审核周期：3–7 个工作日
- [ ] **小米应用商店**
- [ ] **OPPO / vivo 软件商店**
- [ ] **腾讯应用宝**
- [ ] **360 / 百度手机助手**

每家通用材料包：
- 软著登记证书（扫描件）
- 营业执照（个体户）
- 隐私政策 URL（需自建一个隐私政策页）
- 应用图标 512x512、截图 3–5 张、应用简介 200 字内

## 阶段 5：长期运营

- [ ] 自建隐私政策页（可用 GitHub Pages / Vercel）
- [ ] 版本迭代时同步更新软著（小版本可不重新登记，大版本建议补充）
- [ ] 各商店版本号与 Gitee Release 对齐
