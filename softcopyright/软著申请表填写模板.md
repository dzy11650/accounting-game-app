## 六、常见补正原因 & 规避

| 补正原因 | 规避方法 |
|---|---|
| 源代码页数不足 50 行/页 | 确保每页至少 50 行代码行 |
| 源代码无页眉/页码 | 本生成器已自动加页眉（软件名+版本）和页码 |
| 用户手册无界面截图 | 手册中每页配游戏界面截图 + 文字说明 |
| 软件名称不含"软件" | 全称用"会计小当家教学软件" |
| 开发语言填写模糊 | 明确写 JavaScript / TypeScript / HTML / CSS |
| 权利范围未选"全部" | 明确勾选"全部权利" |
